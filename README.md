## ⏰ Relógio Digital

Um projeto simples e moderno de Relógio Digital desenvolvido com HTML, CSS e JavaScript, que exibe em tempo real as horas, minutos e segundos de forma dinâmica e responsiva.

## 📌 Sobre o Projeto

Este projeto tem como objetivo praticar conceitos fundamentais do desenvolvimento web, como:

- Manipulação do DOM com JavaScript
- Atualização de dados em tempo real
- Estilização com CSS moderno
- Criação de layouts responsivos

O relógio é atualizado automaticamente a cada segundo, proporcionando uma experiência fluida e funcional para o usuário.

## 🚀 Funcionalidades

✔ Exibição de:

 - Horas
 - Minutos
 - Segundos

- ✔ Atualização em tempo real
- ✔ Interface simples e intuitiva
- ✔ Layout moderno com efeito de sombra
- ✔ Design responsivo para diferentes tamanhos de tela 📱💻

## 🎨 Design

O projeto conta com um visual limpo e moderno:

- Fundo com gradiente vibrante
- Cards individuais para cada unidade de tempo
- Tipografia legível e destacada
- Efeito de profundidade com box-shadow

## 🔮 Tecnologias Utilizadas

- HTML 🟧
- CSS 🟦
- JAVASCRIPT 🟨

##  Responsividade

O layout foi desenvolvido para se adaptar a diferentes dispositivos:

- 📲 Celulares pequenos e grandes
- 📱 Tablets
- 💻 Desktops


## 🎯 Objetivo

Este projeto foi criado com foco em:

- Praticar desenvolvimento front-end
- Aprender manipulação de tempo com JavaScript
- Criar interfaces simples, mas eficientes
